 كيفاش خدام؟
──────────────
1) المكوّن كيقرا الـ id من الـ URL (مثلاً /products/51151 → 51151)
2) كيسقسي /api/products/51151 → cj_product_id (SELECT * كيرجعو أصلاً)
3) نداء واحد للبريدج /api/cj-live/product/:cjPid
   → shipping.options = أفضل 3 قنوات CJ (اسم + سرعة + ثمن داخلي)
   → الأزرار كيتبنو منهم مباشرة
