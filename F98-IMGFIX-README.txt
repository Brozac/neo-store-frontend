F#98 — IMGFIX: عداد صور المنتج ولّى بناقص سالب ("-20 / 14")
══════════════════════════════════════════════════════════════════

البلاغ (15 نوفمبر 2026):
  فـ lightbox الصور تاع المنتج، العداد فوق كيولّي بناقص سالب — فالـ capture: "-20 / 14"
  والصورة الرئيسية كتبان "معلقة" (ما كيتبدلش) واخا كتسكرولي.

الجذر الحقيقي (bug واحد، حرف واحد):
  سهم Next (→) تاع الـ lightbox كان فيه prev - 1 بالغلط، الصح prev + 1.
  يعني ملي توصل لآخر صورة (13 فـ معرض ديال 14):
    next → 13 يرجع لـ 0 ✓ ... ولكن من 0: "0 === 13?" لا → 0 - 1 = -1 ← البداية تاع الهبوط
    ومن -1: "−1 === 13?" لا → -2 → -3 → ... بلا نهاية
  العداد كيبان = index + 1 → عند index = -21 كتشوف "-20 / 14" (نفس الـ capture بالضبط)
  والصورة كتبقى على الأولى حيت galleryImages[-21] = undefined → fallback لـ galleryImages[0].

الإصلاح (+22 / −6 — ملف واحد برك: app/products/[id]/ProductDetailsClient.tsx):
  1) navImage(dir) — تنقل دائري بـ modulo حقيقي: مقاوم حتى لو الـ index خرج من المدى،
     ما يوليش سالب أبداً (محاكاة: next ×25، prev من 0، index خارج المدى، معرض ديال صورة واحدة ✓)
  2) السهم Next تاع الـ lightbox ولّى navImage(1) — هادا هو السطر اللي كان مكسّور
  3) كل نقاط التنقل الست ولات نظام واحد: سوايب الموبايل · أسهم الديسكتوب · أسهم الـ lightbox
  4) clamp effect: ملي كيتبدل طول المعرض (صورة الفاريانت كتزول قدام → 15↔14 صور)
     الـ index كيرجع للمدى — زال حتى بلاغ "15/14" المحتمل
