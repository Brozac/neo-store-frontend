 شنو الجديد؟
─────────────
كل الإيموجي اللي كيشوفها الزبون (~140 موضع فـ 35 ملف) تحولو لأيقونات
Lucide داخل شرايح زجاج مضبّب (backdrop-blur + حدود رقيقة + لمعة داخلية):

  ✅ GlassIcon.tsx — المكوّن الأساسي:
     • <GlassIcon i="truck" />    → أيقونة مسمية داخل شريحة زجاجية
     • <GlassIcon ch="📦" />      → من حرف إيموجي (خريطة أوتوماتيكية 55+)
     • <GlassIcon i="zap" bare /> → أيقونة عارية للأزرار/الشارات
     • <GlassInline text={label} /> → نصوص جايين من strings (statuses/badges)
     • إيموجي غير ممرّغ → الشريحة تحتضن الحرف نفسه (ما كاينش فقدان)
     • الأعلام 🇩🇿 ما كيتمسوش (محتوى ماشي أيقونة)
  ✅ GlassDock.tsx — dock زجاجي عائم فأسفل الشاشة:
     Home · Shop · Cart · Orders · Track — بالتظليل النشط — كيخفى فـ /admin
  ✅ DeliveryEstimator v6 — زجاجية: Plane/Truck/Zap/Check بلا إيموجي
  ✅ 35 ملف كستمر: الـ hero · الكروت · السلة · الطلبات · البروفايل · التتبع…
  ✅ صفحات الأدمن ما تلمست · عجلة الحظ (SpinWheel) بقات بالإيموجي ديالها
     (شخصية اللعبة) · options الديروب داون بقاو نص صافي (المتصفح ما كيقبلش JSX)

 اقتصاد/أداء
─────────────
• lucide-react موجود أصلاً فالمشروع — بلا تبعية جديدة
• الأيقونات SVG خفافين · backdrop-blur غير فالشرايح الصغار

 التركيب
─────────
1. حل الـ zip داخل جذر الفرونت (المجلد اللي فيه next.config.ts)
2. دبل-كليك INSTALL_FRONTEND.bat  (أو: python patch_glassdock.py)
3. npm run build → deploy

 التحقق
────────
• python verify_glassdock.py (فجذر الفرونت)
• الرئيسية: شارات زجاجية فالـ hero والكروت + dock عائم فالأسفل
• /orders و /profile: حالات الطلبات بأيقونات زجاجية

 التراجع (Rollback)
────────────────────
كل ملف معدل عندو .bak-kit29h بجانبو:
  copy /y "app\layout.tsx.bak-kit29h" "app\layout.tsx"
(وكل ملف آخر بنفس الطريقة) ثم npm run build → deploy.

 ملاحظات
─────────
• الملفات الجديدة (ui/GlassIcon.tsx · ui/GlassDock.tsx) كيتصاوبو من جديد
  كيما هوما — إلا عندك ملفات بنفس الاسم بلا ماركر، الپاتشر كيوقف fail-closed.
• الأزواج الجراحية lenient: إلا الملف تبدل عندك من قبل، الأزواج غير
  المطابقة كيتسكيپاو بلوج — الملف كيبقى صالح دائماً.
