 LaClarc — كيت 29j [variant-truth] — محرّك الفاريانت الحقيقي
═══════════════════════════════════════════════════════════════

شنو كيصلح؟
──────────
🔴 باغ مالي خطير: الزبون كان يختار اللون والمقاس، والكود القديم كان
   كيفشل فمطابقة اللون دايماً (كيقارن hex مع اسم) — فيطلب من CJ
   أول لون موجود فنفس المقاس. مثال حي: تختار Army Green+XXXL
   → يوصلك Yellow+XXXL. درك: الفاريانت كيتلقا داخل عائلة اللون فقط.

🆕 الجديد اللي كيشوفو الزبون:
   • سواتشات الألوان = الصور الحقيقية تاع كل لون (من variantImage تاع CJ —
     100% معمّرين فالكاتالوغ) — كيما Temu/Shein.
   • اختيار اللون كيبدّل الصورة الكبيرة للصورة الحقيقية تاع ذاك اللون.
   • المقاسات كيتبانو غير المتاحين فعلاً فاللون المختار (2XL/3XL
     اللي كانو مخبين كيبانو دابا) ومرتّبين S→M→L→XL→2XL→3XL.
   • الـ vid اللي يمشي للـ order صحيح 100% = بضاعة صحيحة = ريفونات أقل.

⚠️ علاش ما كاينش "ثمن الفاريانت"؟ درس اللايف (منتج 96814) بيّن أن
   variantSellPrice تاع CJ = كلفة الجملة (wholesale) ماشي سعر البيع —
   عرضها للزبون كان غادي يسريب الهوامش. سعر العرض والـ checkout
   كيبقاو من DB (Bank-Grade) — نفس فلسفة Task 9.

التجهيز (Windows):
──────────────────
  1. حل laclarc_variant_truth_kit.zip فجذر الفرونت (حيث package.json)
  2. python patch_variant_truth.py
  3. python verify_variant_truth.py
  4. npm run build  →  deploy

──────────

  • Backup: *.bak-kit29j (الأقدم ما يتمسش) — الرجوع: نسخ الملف من الـ backup.

    للعرض فقط (نفس فلسفة Task 9).
