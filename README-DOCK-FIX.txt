 Kit 29i [dock-dedup] — تصليح التداخل: زوج docks فوق بعضاهم
════════════════════════════════════════════════════════════════

 المشكل اللي شفتو
──────────────────
فأسفل الشاشة (موبايل) كانو زوج شريطات مركوبين فوق بعضاهم:
  • الشريط الأصلي تاع الموقع (الأيقونات الوردية + النقطة + badge السلة)
  • الشريط الزجاجي الجديد (Home/Shop/Cart/Orders/Track — اللي جاء مع كيت 29h)

 السبب
───────
كيت 29h زاد dock زجاجي جديد وركّبو فـ app/layout.tsx، لكن نسی
يحيّد الـ dock الأصلي اللي مركوب من قبل فـ app/providers.tsx
→ زوج يربحو نفس البلاصة = التداخل اللي شفتو.

 شنو كيدير هذا الكيت
──────────────────────
يحيد غير سطرين من app/layout.tsx:
  • import GlassDock from '@/components/ui/GlassDock';
  • <GlassDock />  (قبل </body>)
والـ dock الأصلي يبقى هو الوحيد — هو اللي:
  • فيه badge ديال السلة (عدد المنتجات)
  • فيه فيزياء التكبير مع الماوس (magnetic)
  • فيه Wishlist + Profile + Browse (6 وجهات بلاصة 5)
  • وهو أصلاً الـ "GlassDock" الأصلي تاع الموقع

 ⚠ المهم: كلش آخر من كيت 29h كيبقى كيما هوما
────────────────────────────────────────────
الشرايح الزجاجية (GlassIcon) فـ 34+ ملف، Estimator v6، كلش محفوظ.
غير الـ dock المكرر هو اللي تتحيد.

 التركيب
─────────
1. حل الـ zip داخل جذر الفرونت (المجلد اللي فيه next.config.ts)
2. دبل-كليك INSTALL_FRONTEND.bat  (أو: python patch_dock_dedup.py)
3. npm run build → deploy

 التحقق
────────
• python verify_dock_dedup.py (فجذر الفرونت)
• فالموقع: شريط واحد برك فالأسفل (تاع الأيقونات الوردية + badge السلة)

 التراجع (Rollback)
────────────────────
