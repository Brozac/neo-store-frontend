آش يدير (طلبك بالضبط):
  فكارت المنتج فاللوائح — كيت 30 v3.1:
    · الشكل:     مربع مضبّب (rounded-md)  →  دائري (rounded-full)
                 = نفس لغة سواتشات صفحة المنتج
    · الحلقة:    داكنة #1D1E3C (temu-black)  →  وردية #FF6B9D
                 (الوردي الرسمي تاع الموقع — نفس تاع السعر والشارة)
                 + الفجوة البيضاء كتبقى (كتقرا فوق أي لون صورة)

  الموقع «النشيط» برك هو اللي كيتقلب وردي — الحدود الخاملة
  الرمادية الخفيفة كتبقى كما هيما (نفس بنترن Temu/Amazon).

  ✔ الصفحة تاع المنتج (PDP) ما تلمسش — هي دائرة أصلاً.
  ✔ غير جوج سلاسل كيتبدلو فـ ProductCard.tsx — المنطق والخدمة
    (hover/click/+N/vid) ما يتلمسو والو.

التاريخ (من اللايف، يوم التنفيذ):
  كارت:  w-5 h-5 rounded-md … p-0  +  border-temu-black ring-2
         ring-temu-black ring-offset-1 ring-offset-white (نشيط)
  بعد الكيت:
         w-5 h-5 rounded-full … p-0  +  border-[#FF6B9D] ring-2

التركيب (دقيقتين):
  1) حل هاد الزيب فجذر الفرونت (جنب package.json)
     — ولا حلّو وغادي يلقاه السكريبت بجواره (طلاعة درجة للفوق)

     ولا من الترمينال:  python patch_swatch_round_pink.py
